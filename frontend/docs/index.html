ARCHITECTURE & SPECIFICATION

Backend API and security model.

Authentication uses SIWE (EIP-4361). Transactions are non-custodial. Quotes are locked server-side and verified against chain state before marked settled.

Security Model: Non-Custodial
Auth Layer: SIWE Challenge-Response

Transaction Lifecycle 
Wallet → SIWE Signature → Authenticated API Session → RFQ Quote / Order Lock → Wallet Execution → Node RPC Verification → Finalized Settlement

A public 0x transaction is not equivalent to a private swap. Privacy claims should only be restored after the audited shielded execution layer is actually integrated.
