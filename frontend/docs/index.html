Backend API and security model.

Authentication uses SIWE. Transactions are non-custodial. Quotes are stored server-side and verified again against the chain before a swap is marked submitted.

Architecture note

Wallet → SIWE → API → quote/order → wallet transaction → RPC verification → settlement

A public 0x transaction is not equivalent to a private swap. Privacy claims should only be restored after the audited shielded execution layer is actually integrated.
